# v0.1.51 — Named canonical drafts

This development successor makes a repeated native editing step shorter without
turning names or source files into a second mutation authority. [Current status](../status.md)
owns source acceptance and actual binary availability; a version or notes file is
not a published release. Public v0.1.50 does not include these new CLI selectors.

## Start an edit by its exact local name

```sh
lkjscript --project site change draft --declaration web::page-title --output title.lkjc
lkjscript --project site change draft --module web --output web.lkjc
lkjscript --project site change draft --target serve --output target.lkjc
```

The declaration route replaces two name-discovery commands and one ID-selected
draft command when the exact local name is already known. `--owner ID` remains
available. Module, declaration and target selections may repeat and mix; their
complete canonical output is deterministic and deduplicates overlapping owners.
The existing complete authored-change count bound also limits selectors to 10,000.

Names are exact, case-sensitive local names. A declaration needs exactly
`MODULE::NAME`; dependency namespaces, fuzzy matches and contract-child paths are
not accepted. Module and target namespaces remain distinct even with the same
spelling. A missing or malformed name fails with `change_draft_selection` before
any draft output is created. All names resolve at the same immutable revision
used for rendering, and each namespace witness is checked against its canonical
owner under shared read and cancellation admission.

Names select the read-only export only. Generated proposals retain exact owner,
repository, package and base identities. A subsequent rename cannot silently
retarget an old proposal. `change plan`, explicit review and `change apply` remain
necessary; no automatic rebase, save, restart or reload is introduced. Existing
output files are never overwritten, and accepted project storage cannot be used
as the draft destination.

## Compatibility and evidence

There is no graph, authored-change, artifact, package, deployment or application-data
format change. Ordinary libraries and compiled programs retain their meanings.
The [campaign](../campaigns/202609270517.md) records copied-executable comparisons,
negative controls, pinned-view and shared-admission tests, the existing detached
web-edit consumer and exact verification/integration state. It separately records
public delivery of the unchanged, previously accepted v0.1.50 lifecycle candidate.
