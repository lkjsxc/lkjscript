# 0.1.94

Development selects native package dependency planning for production logical
package admission and compilation. The ordinary native planner, guarded by its
separately exported complete-outcome checker, owns both cycle refusal and the
dependency-first plan. Rust retains canonical input admission and the strict
artifact reader's independent topology check.

Native graph capacity covers the existing 10,000-package/100,000-edge compiler
closure. The compiler uses a bounded embedding envelope without changing ordinary
CLI JSON defaults. Cancellation reaches native planning, and pure-tool execution
joins cleanup on invocation or encoding failure. Only successfully admitted
immutable code is shared; complete input admission and result plans remain local
to each operation.

CLI observation 46 adds invocation-bound native planning identities and counts to
compilation reporting. No semantic or artifact encoding cut is intended. Candidate acceptance/workload
10 adds maintained native-planner regeneration and copied-product compiler
witnesses. Predecessor receipts retain their original scope. All product version
components remain opaque identifiers.

The [decision](../decisions/native-package-planning.md) records authority,
bootstrap, capacity and canonical-order boundaries. [Status](../status.md) owns
actual validation, integration and publication; this note does not claim those
gates have passed or that native planning is faster than its host predecessor.
