# v0.1.49 — Native editing and a durable web starter

This milestone makes small native edits smaller in the accepted graph, without hiding their
review evidence. [Current status](../status.md) owns actual distribution state; this notes file
alone is not source-wide acceptance, an accepted archive or a publication claim.

## Change a value without recreating a function

A complete native function draft can now change same-kind boolean, integer, binary64, text and
static-text literals while retaining every existing expression and binding identity. The native
normalizer first proves that substituting those values accounts for the entire proposed body.
Types, references, binding scope and child ordering cannot be silently ignored. An independent
typed lowerer admits exact live ownership, scalar kinds, unique selections and resource bounds;
ordinary complete-candidate validation and atomic publication remain required.

A complete native declaration collection may select each existing owner only once. Ambiguous
repeated definitions reject even when their displayed scopes differ or they appear in separate
blocks. They are not merged into an unrequested combination of partial scalar changes. Explicit
precise operations keep their ordinary ordered semantics.

For the matched web-starter edit `Apply dark theme` → `Use the dark theme`, the complete logical
plan shrinks from 80,402 to 8,613 bytes. One existing expression changes; the previous implementation
recreated and retired sixteen expressions. These are measured graph/proof bytes, not execution
speed, model-token usage or monetary savings. Full logical plans remain available as explicit files.

Structural edits, explicit `replace.body`, constant/test/port body changes and uncertain native
correspondence keep their ordinary complete replacement path. No general-purpose heuristic graph
patcher, additional compact command, live reload protocol or browser runtime is introduced.

## Review and compatibility

New scalar-update intents use additive authored codec 19 and commit to the exact function,
ordered expression identities, scalar kinds and values. Earlier intent forms keep their existing
canonical encoding domains. Re-plan requests reviewed under a runtime whose normalization or
capability context differs; old tokens are not reinterpreted as approval of a new plan.

Graph, program-artifact, package-transport and application-data formats do not migrate for this
change. Building edited code still produces an explicitly selected new artifact. Existing
artifacts, running servers, operator descriptors and saved application data are not rewritten.
The exact [campaign](../campaigns/202609261118.md) separates focused tests, source acceptance and
finalized-archive/publication evidence. This behavior is not part of the separately frozen
v0.1.48 producer.

## Create an editable durable web app

`new --template web-editor` removes manual library export/staging from the maintained
native browser editor. UI, form codec, editor and their tests become editable local
modules, with only the exact built-in standard as an external package. The application
body remains the same native source as the independently packaged example; only an
exact checked linkage preamble differs. Existing projects do not silently inherit
later template changes, and the stateless `web` starter remains unchanged.

The emitted operator descriptor selects a loopback HTTP listener and matching origin,
shared Basic authentication, bounded forms and transactional conditional saves.
A stale or racing update preserves the submitted draft for explicit review rather
than overwriting newer data. Creation and build neither read a secret nor initialize
data. Ordered next actions name the required secret variable and explicit data setup.
`notes.lkjdata` is a directory using the existing storage format, not a new container
format or an automatic migration of existing paths.

The [starter guide](../guides/native-web-editor.md) covers private provisioning,
native edits, immutable deployment snapshots, restart and operational limits.
The [starter campaign](../campaigns/202609261600.md) owns its distinct verification.
This is a bounded shared note, not user accounts, a multi-document system, live
reload, a new language primitive or a Wasm implementation.

## Ordinary library work remains ordinary code

The accompanying [form library](../guides/native-forms.md) adds bounded UTF-8 form encoding with
ordered duplicate fields, as well as strict decoding. It is separately authored native library
source, not an embedded form-specific intrinsic or a hidden package upgrade. Its independent
public-v0.1.47 proof requires no compiler rebuild; installing a new executable does not silently
change an existing application's library selection.
