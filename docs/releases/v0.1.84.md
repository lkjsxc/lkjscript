# v0.1.84 — Whole immutable prepared witness nodes

Prepared implementation catalogues, prerequisite edges and function applications
now share complete immutable witness nodes. Exact declaration, ordered type
arguments and ordered prerequisite identities remain distinct. This removes
redundant record headers and type-argument copies without changing authored meaning,
effect authority, scoped ownership or resource capacities.

Ordinary and parallel runtime admission require the exact node in the current
preparation's catalogue before memoized traversal. Equal IDs, equal copied records
and foreign preparation handles reject. Existing full-depth, prerequisite, resource
and cancellation admission remains required. Whole-node construction reserves
modeled storage before growth and admits exact/N-1 byte and work boundaries.

The [complete recursive consumer](../../examples/concrete-callable-proof/README.md)
now has maintained public depth-24 authoring, export, borrowed use, reviewed edits,
restoration and source-deleted artifact coverage. The source-matched v0.1.83
predecessor already passes that behavior: this release reduces prepared metadata,
not the minimum version capable of executing the example. Both production and the
independent canonical interpreter retain matched expected results.

[Measurements](../performance.md#whole-prepared-witness-node-sharing) identify the
retained node/slot subset separately from cumulative preparation reservations,
whole-process memory and timing. `Arc` is a replaceable bootstrap mechanism for
immutable compiler/runtime metadata, not a newly imposed language memory policy.

No meaning-graph, interface, type-object, bytecode or artifact encoding changes.
No application data migration or production deployment is performed. Product
components are opaque identifiers, not compatibility or maturity signals.
[Status](../status.md) owns actual acceptance and immutable-publication availability.
