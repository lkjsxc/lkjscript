# v0.1.89: checked, lookup-free map projection

Production map entry enumeration no longer enumerates each key and searches from
the root again. A sealed cursor borrows one admitted immutable map and projects
only its actual entries in key order. It preserves the exact prepared-program
origin and cannot accept a caller-selected raw value or asserted proof.

This removes the logarithmic search factor from tree traversal. It does not remove
entry-record allocation, persistent list construction, payload clone-spine work,
input admission or program preparation. Shared key buffers remain shared; owned
clone storage is reserved before copying. Refusal and cancellation expose no
successful partial result and preserve previously retained map versions.

The reference evaluator keeps its separate lookup-based implementation. Runtime
regressions compare complete results, foreign-origin rejection, concealed invalid
last children, actual insertion/removal shapes, explicit resource limits,
interrupted clones and subsequent recovery. A literal native workload is authored
and checked through a copied product, then tested after its source and supplier
transport are deleted. Its separate ordered-map oracle checks complete results,
while a paired length control isolates repeated enumeration visits.

Final archive acceptance now requires the exact detached Map matrix and every
enumerated Map-family case against the extracted executable. Its 192 complete
results retain independent expected values, complete input admission, source
deletion, resource refusal/recovery and cleanup checks. Explicit candidate
selection and executable identity checks prevent development-binary substitution.
Missing, substituted, duplicate, ignored, failed or unexecuted cases reject.

Final-candidate acceptance and its native-public workload advance together to
generation 4. Old and mixed generation 3/4 terminals cannot certify this coverage;
all source, target, pinned-userland, installation and public boundaries remain.

See [the decision](../decisions/checked-map-entry-projection.md),
[public workload](../../examples/map-entry-projection/README.md) and
[acceptance status](../status.md). Modelled tree visits are not wall-clock speed,
whole-language performance, copied-byte totals or RSS. Matched measurements retain
preparation and invocation separately, including controls and unfavorable samples.

This source selection also retains the independently checked native dependency
outcome interface: successful plans and exact negative source diagnoses are checked
against the complete proposal. A native report does not become publication or
execution authority. The production compiler is not replaced by that witness.

No source graph, type, interface, artifact, application-data or observation encoding
changes are introduced by the map mechanism. Identifiers remain opaque rather than
compatibility promises. Finalized-archive acceptance and actual public availability
are separate from source acceptance; this note alone does not establish publication.
