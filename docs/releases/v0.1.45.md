# Native development tools and explicit resident quotas

## Ordinary programs, reusable operations

The standard library adds pure `text-join(List<Text>, Text) -> Text`.
It preserves order and exact text, inserts separators only between items,
and handles empty and singleton inputs. Its balanced implementation and tests
are ordinary lkjscript. Escaping and formatting remain caller policy.

`bytes-get(Bytes, I64) -> I64` reads a zero-based unsigned octet without text
conversion or mutation. Invalid indices trap. This runtime operation supports
the native repository-policy program without expanded integer-list inputs.

The maintained native guide program now renders all eight reference pages and
validates required references. Another native program owns extension and bounded
raw-byte shebang decisions for the required no-Python gate. Rust keeps metadata,
filesystem observation and orchestration. Native tool adoption is not compiler
self-hosting; measured tooling costs remain in the implementation campaigns.

## Explicit resident policy

Four independent execution quotas accept a positive number or explicit null:
instructions, cumulative allocated bytes, collection items and invocation calls.
New HTTP and relay-information recipes select four nulls. Operational deadlines,
cancellation, call depth, value stack, concurrency, stream bounds and exact grants
remain independent controls. Counters are per invocation. Allocation work is not
RSS or live-heap size, and these controls are not a hostile-code sandbox.

## Compatibility and recovery

Existing numeric descriptors preserve their original behavior. Omitting the three
new fields keeps the legacy allocation, collection and invocation-call limits;
only explicit null removes a selected quota. Required policy objects and structural
limits remain required. Zero does not mean unlimited. Discovery advances to
deployment contract 5; graph, artifact and application-data formats do not change.

Older executables reject null fuel and the new fields. Retain the old executable
and descriptor for rollback. Rust embedders must adapt RunPolicy: instruction_fuel
is now Option<u64>, with three additional quota fields. RunPolicy::unmetered()
selects all four absent quotas. See docs/guides/resident-policy.md for examples.

New projects select the embedded standard; existing exact suppliers remain exact.
The new byte intrinsic needs a compatible runtime. Runtime selection performs no
application-data migration and an artifact still requires its runtime executable.

## Contributor execution and distribution

The shared contributor process owner retains deadlines, output bounds and
cancellation after direct-child exit, delays reaping until final group signaling,
and joins observed descendants. Executable evidence binds both the selected entry
and resolved target. Procfs sampling is not complete hostile-process containment.

Distribution remains the static x86_64-unknown-linux-musl executable, archive,
checksum and installer. Candidate acceptance, immutable publication and anonymous
exact/latest installed verification are separate stages. The delivery record is
in docs/campaigns/202609250650.md; these notes alone do not establish publication.
