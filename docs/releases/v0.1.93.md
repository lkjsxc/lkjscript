# v0.1.93 — checked consuming extraction

Consuming an admitted owned product or nominal record preserves the admission of
its ordinary immutable fields. Large nested metadata can leave its owner without
a second recursive admission walk. Owned children still receive exact-type,
current-domain, custody and allocation-admission checks.

The [extraction decision](../decisions/checked-owned-extraction.md) defines the
sealed boundary and failure behavior. Raw input, packing, captures and transfer
retain independent admission; the reference evaluator remains an independent
recursive checker. Extracted values retain no parent owner or loan.

The maintained metadata workload checks complete input and reduced repeated work.
The indexed-storage witness retains full nested displaced values after destroying
Flat and Chunk32 storage, including detached execution and failure recovery.

This runtime change requires no semantic or artifact format cut. Preparation,
invocation, modeled work and retained memory remain separate costs. Exact accepted
source, measured results, mainline delivery and publication belong to
[current status](../status.md); source evidence does not attest distributed bytes.
