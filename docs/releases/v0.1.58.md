# v0.1.58 — Exact deployment requirement selection

Status: development source; no distribution acceptance or publication is implied.

## Changes

Deployment grants can select an existing exact package/requirement identity:

```json
{
  "requirement": "pkg_0123456789abcdef0123456789abcdef/req_fedcba9876543210fedcba9876543210",
  "sharing_domain": "application-jobs",
  "authority_revision": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "adapter": {
    "kind": "configuration"
  }
}
```

The IDs above are illustrative. Obtain real identities from public package export
and canonical declaration drafts; the chosen artifact must contain the exact
requirement in its selected component. Adapter kind and limits must still match
that requirement's declared interface and operations.

Independent requirements named `jobs` can now bind separate adapters and stores.
Name-only selectors remain accepted when unique in the complete component.
Selecting one requirement exactly does not disambiguate another by elimination.
Named/exact duplicates, foreign or unused requirements, malformed IDs, missing
grants and ambiguous names reject before secret lookup or live preparation.
Static admission, stream relationships and preparation share exact references.
Redacted readiness preserves each supplied selector instead of collapsing equal
names.

## Compatibility and limits

The descriptor object shape is unchanged. Deployment discovery contract 6 names
the existing string field `requirement-selector`. Existing valid name-only
descriptors need no rewrite; older executables reject qualified selectors.
Keep matching executables and descriptors when rolling back. No graph, artifact,
package or application-data migration is required.

This does not add resource-returning functions, general memory references,
effect/requirement-polymorphic resource transfer, region allocation or zero-copy
payload processing. It does not change per-grant operations, limits, sharing
domains, authority revisions or affine provenance rules.
