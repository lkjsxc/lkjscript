# v0.1.82 — Compact proof for acyclic callable composition

Complete callable-flow admission now discovers the exact selected call graph
before expanding prerequisite type-provenance paths. Only calls within the same
recursive component require the full type-growth proof. A type-slot cycle must
project to a callable-context cycle, so removing inter-component proof edges does
not remove a possible expanding cycle.

Every declaration, unused method mapping, function value and untaken expression
remains in source admission. Calls and concrete witnesses still validate every
ordered type argument, including phantom arguments, missing type objects and
foreign lexical parameters. Recursive contexts retain distinct prerequisite paths:
equal witness shapes do not imply equal type provenance. Existing rejection of
potential recursive witness construction, exact method/implementation identity,
ordinary recursion, parameter permutation and closed resets remains unchanged.

The [public workload](../../examples/compact-callable-proof/README.md) authors and
exports a 24-layer generic reader library before concrete items or consumers
exist. A separate consumer uses bounded concrete layers with two same-Self readers,
borrows the original cell, and then extracts its unchanged value. Canonical
edit/restore and detached artifact execution preserve exact selected identities.
Foreign prerequisites and extra operands reject without publishing their proposals.

A retained baseline previously exhausted 1,000,000 modeled work units on the
24-layer typed-DAG probe. The compact proof admits that probe with 237,852 units
and 875,299 bytes of cumulative modeled metadata reservation. These are internal
admission counters, not elapsed time, peak live memory or process RSS. Small
fixtures compare the compact proof with an unpruned reference mode. An independent
weighted transitive-closure oracle retains 1,296 combinations of permutations,
resets, phantom slots and structurally nested parameter occurrences.

This does not make all generic preparation compact. Recursive type-provenance
paths, the number of exact contexts and concrete prepared-witness materialization
remain separately bounded. No execution limits or grants are changed. Graph,
interface, type-object and artifact encodings retain their current identities;
the change selects a smaller derived proof without changing accepted meaning.

[generic implementation contract](../spec/generic-owned-implementations.md).
[Status](../status.md) separates source acceptance, final-byte acceptance and
public availability. Source tests alone do not attest a distributed archive.
