## Selected responsibility

The ordinary editor already receives decoded `forms::field` values, but its
`fields` function previously mapped them into HTTP-header-shaped records, converted
Text to Bytes, reused a header lookup three times, then converted values back to
Text. This is a concrete misplaced responsibility, not a missing compiler feature.

Add ordinary `forms::lookup(fields, name) -> selection`, with nominal `missing`,
`present(Text)` and `repeated` cases. An empty value is present; equal duplicate
values still repeat. Exact decoded names retain case, Unicode normalization form,
BOM, NUL and percent-looking text. The function traverses the existing immutable
list and stops at a second match or the end. It does not collapse the list, perform
decoding, enforce an HTTP limit or convert operational failures into a data result.

The editor consumes the typed result through a small domain adapter. Its exact
three-field contract, error text, base admissibility, note cleaning, actual HTTP
header policy and conditional transactions remain unchanged. The base alone still
becomes Bytes for its existing public numeric-admission function. Header admission
continues to own actual headers, not decoded form values.

The independent ordinary command consumer exposes the new result and keeps decode
errors distinct from missing fields. Both existing codec interfaces and the HTTP
report receiver remain supported. No privileged renderer, form opcode, schema
generator, new runtime dependency or new graph/package/data format is introduced.
This is a responsibility and reuse improvement, not a throughput, zero-copy or
universal instruction-count claim.

Exact accepted suppliers are not silently replaced. The new literal library and
editor can be authored with a compatible existing executable; updating the main
examples does not modify a previously downloaded executable's embedded starter.
