Ordinary generic helpers already prove their exact final resource contract.
A call-graph cycle does not invalidate that local proof: each finite activation
borrows a non-owning view or transfers one owned value, and every function body
is independently checked. Remove the additional acyclicity veto, not the
ownership checks. Termination remains separate from affine safety.

The implementation retains private same-package signatures, concrete effect and
requirement identity, resource-free ordinary arguments/results, final-local
transfer, borrowed-handle attenuation, and no resource-bearing callable values.
Existing generic instantiation, task execution and cleanup mechanisms remain the
owners. No new loop primitive, alternate evaluator, capability, or runtime
resource representation was introduced. Automatic extraction stays narrower.
