including untaken cases; at least one must carry direct owned data. Other cases

exact live owned local when that case is owned. Complete consuming case analysis
binds exactly one payload in one body-only lexical scope. Distinct arms can reuse
names, never identities or consumption rights. Existing whole-owner synchronous
loans compose; borrowed selection, escaping references and mutable loans do not.

inspection, exact package transport, independent ownership checking, strict compiled
