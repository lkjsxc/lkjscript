## 5. Target semantics, scope, and non-goals

### 5.1 Public typed operation

Add exactly one operation, `extract.function`, under `change`; add no top-level command or alias.
Fields:

- `as`: request-local symbol for the helper declaration;
- `function`: exact or unambiguous local declaration selector existing at the base;
- `expression`: exact live expression owner in that function's structural body closure;
- `name`: explicit absent declaration name in the same module.

Existing base/plan/idempotency/intent/file/output/apply controls remain authoritative. The helper
is private, same-module, named, and nongeneric; the expression is a proper subtree. Admit one
extraction per request and reject another operation touching its closure, parent edge, helper, or
captures. Direct/file forms normalize identically. Discovery owns fields, bounds, diagnostics,
authority effects, and nonclaims; aliases and noncanonical records reject.

### 5.2 Closure and inferred contract

Materialize the exact definition before planning. The movable set is the selected expression plus
all structural descendants. It has exactly one structural incoming edge from its current parent and
no foreign structural alias.

Free locals are local references whose function parameter, lexical binding, or match binding lies
outside the movable set. Bindings defined inside must not escape. Declaration, constant, type,
operation, requirement, and package references remain exact references, not captures.

Order captures by first canonical use, then owner key. Resource-free captures become unrestricted
parameters. Reuse unambiguous bound names; resolve collisions by one deterministic identity-derived
spelling exposed in plan/discovery. Admit at most one free capability resource. It must be consumed
inside the subtree, have no later use, satisfy the current affine handoff shape, and become the final
`consume` parameter bound to its exact acquiring requirement. Borrow-only, multiple, contained,
escaping, foreign, mismatched, or post-call resource use rejects.

Infer the exact resource-free result type. Infer the least effect: `pure` with no task requirement,
otherwise `task` with the exact needed subset of the caller's requirements in caller order,
including the affine requirement. Never infer authority from names, grants, handles, or host data.

Reject generic/free-type targets, target recursion/cycles, cross-package meaning, escaping
bindings, unsupported resource/result shapes, unprovable closure, namespace collision, malformed
ownership, or any bound. Moved owners, captures, requirements, generated owners, reads, bytes,
validation, and output have separate executable-owned finite limits; never truncate.

### 5.3 Identity-preserving rewrite and failure

records whose free target becomes a helper parameter.

Create the helper/parameters, one direct call at the original occurrence, and minimal local argument
expressions. Replace the exact parent edge with that call. Arguments are already-evaluated local
reads in parameter order, with any consumed resource last; no computation/effect/failure/resource
transfer moves across a sibling evaluation boundary.

The plan identifies base definition digest, selected root, moved-owner digest/count, capture mapping,
inferred contract, affine provenance, preserved/changed/generated owners, caller/helper counts,
