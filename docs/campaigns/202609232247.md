## Implemented boundary

The accepted native project owns `markup` and `guides`, with 332 root owners,
eight native tests and the exact v0.1.44 standard supplier's 45 tests. It builds
the 794,397-byte code-complete `generated/guides.lkja` artifact. Native functions
own balanced Text concatenation, escaped HTML tables/code blocks, typed row
projection, header and complete operation/diagnostic layout. Both public guide
commands actually execute this embedded artifact; the two old Rust formatters
are deleted. The other six document outputs remain byte-identical.

The shared internal pure-artifact invocation has no ambient grants, no source
repository and no reference-equality claim. It uses normal target/type/JSON
admission, checks both task identity and component requirements before execution,
and preserves cancellation and output limits. The host uses ordinary trusted
foreground policy, not mandatory cumulative metering. Its registry adapter only
observes fields and calls the native tool; no compiler or external-document opcode
was introduced. Artifact/graph/data contracts and the standard supplier are unchanged.

owner: exact canonical artifact regeneration, 53 differential tests, copied-product
fresh authoring, explicit independent expected text, canonical no-op re-entry,

inputs/project/transport. It clears PATH and external process environment. Native
adapter tests independently cover escaping, columns/order, typed-record rejection,
cancellation and result bounds. The shared runner tests reject real capability
components and empty-effect tasks while accepting the corresponding pure callable.
