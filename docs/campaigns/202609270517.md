## Chosen next product increment

the next useful seam. Known local declarations previously required two separate
queries, manual ID transfer, then a draft command. Development v0.1.51 adds
repeatable `--module NAME`, `--declaration MODULE::NAME` and `--target NAME` beside
strict `--owner ID`. One pinned accepted view resolves and renders all selections.
Names select only read-only reconstruction; output and later mutation remain bound
to exact IDs, repository, package and revision. Missing names reject the entire
export. Canonical class/parent/name checks, cumulative physical admission,
cancellation, bounded complete output and absent-destination publication remain.

The maintained native web scalar-edit/detached-snapshot test now uses the named
route while retaining independent exact-ID queries for its identity assertions.
The operation registry, semantic CLI specification, generated discovery, and web
and durable-editor guides describe the new route without advertising it in v0.1.50.
Graph, authored-change, artifact, package, deployment and data formats are unchanged.
