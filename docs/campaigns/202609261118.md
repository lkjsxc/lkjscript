recipe. Recognize same-structure function edits changing only scalar literals.
Retain existing expression/binding identities and update only changed literal
values. Structural edits retain explicit whole-body replacement and retirement.

with exactly the selected literal substitutions, using the existing canonical
authored-intent encoder. Mere matching traversal counts, masked shapes or displayed
names are insufficient. An uncertain correspondence falls back to replacement.
