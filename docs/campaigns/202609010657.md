## 6. Target state, scope, and decisions

### 6.1 Public dependency and topology records

Add exactly this compact semantic slice through the existing request, plan, apply, budget, relation,
validation, and publication contracts:

```text
add.dependency package=PKG semantic-revision=REV package-revision=PACKAGE_REVISION
create.component as=$COMPONENT module=MODULE name=NAME visibility=private|package|public
add.port as=$PORT component=COMPONENT name=NAME type=TYPE function=DECLARATION
create.target as=$TARGET name=NAME component=DECLARATION port=PORT runner=command|http
```

Generated grammar owns final punctuation and reference spellings; the semantics above are mandates.

- `add.dependency` accepts only an exact binding whose immutable transport is available through the
  current closed built-in mechanism. It performs no network, registry, ambient-directory, or
  unchecked-file lookup. Duplicate, stale, foreign, mismatched, or unavailable bindings reject.
- `create.component` creates an empty component. Existing `add.requirement` and new `add.port`
  populate independently budgeted child owners rather than an unbounded nested payload.
- `add.port` is function-backed only. Its explicit function type and exact function implementation
  must agree. Expression-backed ports remain private.
- `create.target` binds exact component/port identities and one finite runner. Validation rejects
  cross-component ports, absent/retired owners, incompatible function/effect shape, missing
  requirement closure, and runner mismatch.
- Request-local forward references work across the request. Each operation participates in strict
  decoding, canonical commitment, allocation, logical plan, owner/relation/impact evidence,
  validation/tests, idempotent re-preparation, limits, and bounded output.
- Existing stale-base, plan-token, conflict, cancellation, resource, and atomic-publication behavior
  applies unchanged. Do not add a `new`-only bypass.

Do not expose `SetTarget`, arbitrary package transports, dependency deletion, expression-backed
ports, all remaining private mutations, or compatibility aliases merely for symmetry.
