## 5. Target semantics, migration, and non-goals

### 5.1 Canonical requirement binding

Add one canonical optional function-parameter field equivalent to `resource_requirement: RequirementReference`;
exact Rust shape is latitude. It must:

- be present exactly for the admitted resource parameter and absent elsewhere;
- name a requirement in the owning task function's effect whose exact interface matches the direct
  capability-resource type;
- participate in canonical encoding, validation dependencies, relations, summaries, impact, definition
  projection, compiler/artifact identity, and diagnostics;
- survive deterministic plan/apply and exact-base reprepare; and
- never be inferred from names, ordering, deployment grants, or runtime values.

Extend existing `add.parameter` with one optional exact `requirement` field. Add no operation or alias. Omission
stays canonical for ordinary unrestricted parameters; an unbound resource function parameter rejects. Definition
inspection renders the binding and call transfer within current pagination/resource bounds.

### 5.2 Admitted affine call slice

Admit only:

- private same-package task callee and direct named `call`;
- exactly one direct resource parameter, final in parameter/argument order, `consume`, with the exact binding
  above;
- resource-free unrestricted preceding parameters and result;
- the same exact requirement identity in caller and callee, not merely an equivalent interface;
- no generic resource/task function; and
- an acyclic direct-call graph for resource-bearing signatures. Self/mutual recursion rejects; resource-free
  recursion is unchanged.

Arguments evaluate left-to-right. Ordinary arguments finish first. Evaluating the final resource argument
consumes one exact live lexical owner and commits transfer. The caller cannot use it again. The callee may
borrow, consume through the exact capability operation, drop, or forward it to another admitted acyclic helper.

After commitment, call/callee failure, cancellation, exhaustion, or possible external visibility does not
restore caller ownership. Unwind drops remaining local authority; task cleanup does not implicitly complete,
fail, or cancel the queue lease. Existing branch-join rules extend to function parameters. Failed/stale semantic
publication leaves semantic, derived, and operational authority unchanged.

Compiler, loader/preparation, VM, and reference execution must reject hostile inconsistency: wrong
requirement/interface/scope/kind, unsupported use/shape/call/recursion, aliasing, duplicate or post-move use,
resource result, or revived handle. Host frames cannot become parallel authority.
