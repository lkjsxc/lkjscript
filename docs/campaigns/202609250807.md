## Next consequential work

Keep UI and HTTP library responsibilities ordinary and separable. The next useful
extension is typed, server-owned state-changing actions with explicit validation,
error rendering, authorization/origin protection, and honest transaction/retry
semantics. Prove one durable application through the public binary before selecting
a browser event bridge. A generated client or Wasm backend is a later independent
execution boundary, not a prerequisite for useful native-authored pages. Also obtain
permitted live-browser end-to-end evidence; offline checks do not replace it.
