# Principles

## Purpose

Ranked invariants that shape every change.

## Ranked List

1. Honest gates beat aspirational claims.
2. Prefer shallow multi-def and multi-file over deep nests.
3. Keep the host small; grow capability in `.lkjscript`.
4. Limits are tunable policy knobs.
5. Dense bytecode and tagged values stay cache-friendly.
6. Docs and code move together.
