# Principles

## Purpose

Ranked invariants that shape every change.

## Ranked List

1. Honest gates beat aspirational claims.
2. Prefer shallow multi-def and multi-file over deep nests.
3. Keep the host thin and syscall-shaped; grow capability in `.lkjml`.
4. Prefer one resource-efficient machine runtime with isolated logical processes,
   shared immutable work, and explicit global budgets.
5. No new third-party Rust crates without an ADR; prefer owned scratch code.
6. Do not add fat host “feature” opcodes when a script library could own it.
7. Limits are language constants / policy knobs, not sacred forever.
8. Dense bytecode and tagged values stay cache-friendly and JIT-ready.
9. Docs and code move together.
