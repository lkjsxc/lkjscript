# Evidence-gated roadmap

The semantic-development, `lkjwork`, and first `lkjstudio` verticals are implemented in the current
checkout. This file records reversal gates and named missing consumers. It is not a feature queue and
does not authorize ambient authority, compatibility paths, or speculative infrastructure.

## Semantic project and authoring

Full canonical snapshots plus compact revision records remain selected. Reopen storage only when a
representative maintained project exceeds 256 MiB before 1,000 revisions, optimized ordinary open
exceeds 5 seconds, deep doctor exceeds 10 minutes at 100 revisions, or path/backup count crosses a
named deployment limit. A replacement must preserve one publication owner, exact arbitrary history,
tombstones, unknown visibility, portable backup, hostile decoding, and a full reconstruction oracle.

All reads still hold the engine authority lock. Introduce immutable concurrent snapshot readers only
for a measured multi-client workflow after path substitution, snapshot lifetime, mutation
interaction, admission, shutdown, and deterministic response order are proved. A daemon, branch,
merge, or rebase is not a substitute.

Closed semantic queries, generated function proposals, exact local edits, fixed post-apply
continuations, known-digest replies, and the foreground project session are the selected authoring
surface. Expand continuation into requested subgraph deltas only if a frozen repeated-edit workflow
reduces total calls or bytes without more stale/correction failures. Add persistent query/target
indexes only after at least 20 percent complete-workflow improvement with bounded rebuild and simple
fallback. Whole-function replacement and full target validation remain independent oracles.

## Editor and rendering

The retained editor is a flat immutable Unicode-scalar sequence rebuilt with checked slice and
concatenate; the earlier application-level element-copy loops were deleted after the 65,536-scalar
paste exposed their fuel cost. Keep the flat representation while complete edit/render/search/undo
workloads remain acceptable. The current 1,000-growing-insert replay takes 10.9 seconds in one warm
release sample and is the named optimization gate: a piece table, rope, line sequence, gap buffer,
or mutable builder must materially beat that complete workflow and preserve the flat oracle before
retention.

The current application indexes scalars, not grapheme clusters. Add grapheme navigation only for a
named user workflow with exact segmentation versioning, combining/wide-character differentials, and
terminal projection agreement. Normalization, case folding, regex, syntax parsing/highlighting,
project-wide search, and derived line/search indexes remain absent.

Full-frame rendering is selected. Add row spans or cell patches only if terminal output dominates a
representative workload and the candidate is at least 20 percent better while reconstructing exactly
the full-frame oracle under wide scalars, combining marks, controls, clipping, resize, and restart.
Styles/colors need an application-owned product consumer and one closed safe projection.

## Interaction topology

Pure foreground state and a sequential loop won. Unsaved buffers are intentionally lost on process
exit; project and file authorities survive in their own owners. Add a recovery journal or hybrid
checkpoint only after a named unsaved-work recovery requirement justifies a new immutable authority,
retention, corruption, cleanup, and unknown-publication contract. Never reuse development history or
file contents as editor undo.

Target test/build/run currently execute synchronously and can block input. Add one bounded worker
only after measured target work violates the product responsiveness gate. The design must bind job
identity and exact project revision, cap queue/work/results, expose cancellation points, reject stale
results, contain panics, and define shutdown. Do not add a general async runtime for terminal input.

A resident daemon requires a demonstrated multi-client or unattended workflow that cannot use the
foreground session. Per-authority mutation remains serial. A bytecode/native tier requires execution
to dominate a complete product workflow and at least 30 percent improvement against the interpreter
differential.

## Terminal and filesystem

The retained terminal consumer uses key press/repeat, paste, resize, signal, EOF, and full frames.
Mouse, focus, key release, style, clipboard, capability negotiation, suspend/resume, and platforms
other than Linux x86-64 remain absent. Add an event only when the semantic keymap consumes it and
malformed/unsupported input, ordering, bounds, and cleanup are closed.

The selected filesystem is Linux `openat2` confinement under one pinned root. It supports list,
regular-file read, no-replace create, expected-digest replace, and reconciliation. Recursive walk,
delete, rename, directory creation, permissions/ownership, binary editing, file watches, multiple
roots, symlink following, mount traversal, and network-filesystem claims remain absent. Add an
operation class only for one workbench command with exact grant, race, publication, and recovery
semantics.

Hard links are not forbidden; device/inode and digest are returned as observation evidence. If a
product requires hard-link isolation, select and prove an exact trust policy before claiming it. The
current adapter has no cross-platform path normalization or case-folding contract.

## Product scope and trust

`lkjstudio` is a semantic workbench and selected UTF-8 file editor. It is not an IDE framework,
binary editor, GUI, language server, plugin system, package manager, collaborative editor, shell,
process supervisor, or hostile-code sandbox. Add a command palette configuration model only after a
small path-free typed settings consumer proves conflict detection, persistence, and deterministic
help from one owner.

Network sync, multi-user authorization, secrets, signatures/provenance, encryption, sandboxing,
remote repositories, branches/merge, database, mutable package resolution, and cross-platform
deployment are separate campaigns requiring complete threat models and products.

Provider/model token classes, cache classes, dated prices, and billing formulas remain unavailable.
Do not estimate tokens or money from request/response bytes. Retain only direct calls, bytes,
processes, elapsed/CPU time, storage, and correction observations.
