# Evidence-gated roadmap

The current product and platform vertical is complete. This file lists only reversal gates with a
named future consumer; it is not a feature queue and does not preserve dormant implementations.

## Product scale

Run the retained 2,000-task / 10,000-mutation stress profile only when a real project approaches the
representative 500-task shape or the current 10,000-transition / 256 MiB limits. If it fails, first
identify whether application scan work, current-manifest size, checkpoint bytes, journal bytes, or
deep audit dominates.

Reconsider fixed 64-revision checkpoints or add interruption-safe compaction only when a complete
project approaches the journal ceiling or backup/deep-audit service becomes unacceptable. Any
replacement must preserve one exact hash-linked authority, unresolved host/idempotency evidence,
backup closure, corruption localization, and full reconstruction oracle. Delete the losing format.

## Product evolution

There is no import or in-place application-state migration. Add one only for an actual incompatible
`lkjwork` upgrade that must preserve deployed continuity. It must name exact old/new applications and
instances, validate a deterministic mapping, define publication/rollback, and never resolve `latest`.
Until then, semantic export plus explicit new project creation is the only interchange surface.

Full-text search, due dates, wall-clock activity, mutable attachments, multi-user collaboration,
network sync, GUI/TUI, and additional renderings remain absent. Activate one only with a frozen
end-to-end user workflow and exact semantics. Do not add an index, time authority, database, server,
or Unicode collation contract speculatively.

## Runtime scale and topology

The one-shot and caller-owned session topologies remain sufficient. Prototype a resident supervisor,
concurrent queries, parallel mutations, scheduler, worker pool, or async runtime only when a measured
multi-client or unattended workflow cannot use them. Any concurrency design must preserve exact
snapshot lifetime, serial per-instance mutation, overload bounds, shutdown, and differential results.

Retain no persistent cache unless restart-heavy repeated product work improves by at least 20 percent
and the cache repays hostile decoding, exact keying, bounds, eviction, corruption, and publication
obligations. Session-local exact-HEAD reuse remains the current winner.

Reopen bytecode, native execution, or executable caching only when interpreter execution—not artifact
validation, application scans, storage, or publication—dominates a complete representative operation
and the full workflow improves by at least 30 percent. The explicit-frame interpreter remains the
differential oracle through any trial.

## Language and values

Add text search, slicing, normalization, case folding, scalar indexing, formatting, higher-order
sequence operations, maps, sets, hash tables, iterators, mutable builders, or generic declarations
only for a current complete application. New operations must state deterministic fuel, traps,
resource accounting, public encoding, release identity, and finite-value behavior.

Reconsider sequence representation only when exact retained-object or construction measurements show
the safe immutable `Arc` route cannot meet a complete workload. A replacement must remain safe Rust,
keep canonical allocate-new accounting/differential, and expose no representation identity.

## Authority and trust

Grant rotation/revocation, secrets, signatures/provenance, hostile-code isolation, encryption,
multi-user authorization, backup archives, and cross-platform deployment are separate campaigns.
Each needs an active threat model and acceptance workflow; none may be inferred from current digests,
private directories, processes, or local OS-account trust.

Exercise another platform before claiming it. Linux x86-64 is the only verified bootstrap target in
the current evidence.

## Agent authoring economy

Measure one real bounded application-function change through task-scoped context and the retained
public build recipe before adding a new source language, module package format, generator, or broader
schema dump. Retain a change only if exact semantic success, files/source bytes opened, action and
observation bytes, correction depth, builds, or elapsed time improve on the same task.

Provider token and price reporting remains unavailable. Add it only when the execution harness
exposes exact model, input/cached-input/output/reasoning token classes and dated prices. Never infer
tokens or money from UTF-8 bytes.
