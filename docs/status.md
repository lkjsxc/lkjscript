# Current status

Updated 2026-10-20. Accepted typed meaning is the sole editable authority.
Production bytecode is checked against an independent canonical interpreter.
Verification has no three-minute requirement; elapsed time is an observation.

## Capabilities

One checkout and one leased Cargo target serve bounded copy-on-write memory
projects, admitted standard packages/programs and one current schema epoch.
Public `tx` preserves symbolic identities, runs impact-scoped differential tests
and publishes atomically. Rejected preparation cannot partly publish. Default
checks retain a bounded receipt and remove joined scratch.

Lexical regions connect allocation, reads, writes, freeze, relative offsets and
digest-bound slab persistence to both evaluators. Runtime generations, custody
and control-flow admission preserve lexical cleanup and joined-child behavior.
The [region specification](spec/regions.md) owns layouts and limits.

The native backend emits standalone Linux x86_64 ELF. The lkjscript-written
Tier 1 backend consumes Rust-admitted LKJCI1 profile 4 and emits ELF or current
`.lkja`. [Native ELF](spec/native-elf.md) and [self-hosting](spec/selfhosting.md)
own contracts. Native allocation remains process-owned until exit.
