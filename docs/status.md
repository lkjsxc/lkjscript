# Current status

Updated 2026-10-21. Accepted typed meaning is the sole editable authority.
Production bytecode is checked against an independent canonical interpreter.
Verification has no three-minute requirement; elapsed time is an observation.

## Capabilities

One checkout and one leased Cargo target serve bounded copy-on-write memory
projects, admitted standard packages/programs and one current schema epoch.
Public `tx` preserves symbolic identities, runs impact-scoped differential tests
and publishes atomically. Default checks retain bounded receipts and remove joined
scratch. Safe Rust, denied lint invariants and the no-Python policy remain intact.

Lexical regions connect allocation, reads, writes, freeze, relative offsets and
slab persistence to both evaluators. The [region specification](spec/regions.md)
owns layouts, custody, generations and lexical cleanup. Native allocation remains
process-owned until exit; this milestone makes no phase-reclamation or RSS claim.

The lkjscript-written Tier 1 backend consumes Rust-admitted LKJCI1 profile 4 and
emits standalone Linux x86_64 ELF or current `.lkja`. Source admission does not
replace that Rust normalization boundary. [Self-hosting](spec/selfhosting.md)
defines the separate Tier 1, Tier 2 and Tier 3 contracts.

## Acceptance and next work

The compiler carrier and independent finite nominal schemas pass VM, canonical
reference, Rust-produced native and lkjscript-produced native validation. Rehashed
negative carriers reach their intended layer. Compiler-carrier name mutation
reaches namespace diagnostic 16; this is input sensitivity, not an emitted-stage
semantic mutation proof. Direct derived graph controls test structural cycles;
they are not hash-consistent cyclic-carrier tests.

Exact candidate acceptance requires the focused harness, staged-tree bootstrap,
changed selection, all 29 fresh full gates and release-target policy inspection.
The unchanged base commit and exact candidate tree bind the verifier before commit.
Terminal outcomes and source identities belong to
`.artifacts/selfhost/accepted-e-source-types/receipt.json` and its bounded component
receipts. All source, proposal, specification and status edits precede those gates.
Git records ordinary integration; no new public release or deployment is implied.

This is not E1-final or Tier 2 completion. Next admit the remaining namespace owner
forms and full contextual read/effect/witness scope, then complete E2 semantic
admission and E3 deterministic source normalization. Tier 2 still requires the
full region/closure/witness profile, source-driven C2=C3 and A1=A2=A3, meaningful
emitted-stage mutations, independent program controls and measured same-process
