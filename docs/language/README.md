# Language

## Purpose

Define the physical source format, expression semantics, imports, and fixed
source budgets of `lkjscript`.

## Status

**Current** for the implemented Edition 2 source, semantic, and execution
slices. Canonical source uses `.lkjscript`; the former LKJML name and `.lkjml`
extension are **Superseded** and unsupported. Markerless Edition 1 is explicit
validation/migration input only. Broader Edition 2 surfaces retain their
[Accepted Target](../decisions/semantics/edition-2.md) status.
