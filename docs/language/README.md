# Language

## Purpose

Define the physical source format, expression semantics, imports, and fixed
source budgets of `lkjscript`.

## Status

**Current.** Canonical source uses `.lkjscript`; the former LKJML name and
`.lkjml` extension are **Superseded** and unsupported.
