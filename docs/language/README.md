# Language

## Purpose

Define the physical source format, expression semantics, imports, and fixed
source budgets of `lkjscript`.

## Status

**Current** for Edition 1. Canonical source uses `.lkjscript`; the former LKJML
name and `.lkjml` extension are **Superseded** and unsupported. Edition 2 and
all of its language surfaces are an [Accepted Target, not
Current](../decisions/semantics/edition-2.md).
