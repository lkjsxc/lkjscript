# Native authoring guides

These guides use public product operations and literal native declarations.
Each guide identifies its tested workflow and boundaries. [Current status](../status.md)
owns executable availability; `lkjscript capabilities` discovers the installed surface.

| Guide | What it demonstrates |
| --- | --- |
| [Web app from one binary](native-web.md) | Editable local UI modules, native title edits and a standalone loopback deployment. |
| [Durable web app from one executable](native-web-editor.md) | Local UI/forms/editor modules, explicit data initialization and secret setup, reviewed edits and immutable deployment builds. |
| [Durable native browser editor](native-editor.md) | Multiline UI, strict admission, authentication, transactional conflicts and source-free restart. |
| [Bounded native form codec](native-forms.md) | Strict UTF-8 input, canonical ordered fields, exact transport, detached commands and POST composition. |
| [Typed UI without browser-code authoring](native-ui.md) | Ordinary layouts, palettes, GET forms and exact response-library composition. |
| [Paged native HTTP list](native-list.md) | Bounded decimal input, reusable list/text operations and detached HTTP execution. |
| [Recent accepted changes](native-history.md) | Read-only revision/receipt history, recorded intent, separate test counts and explicit truncation. |
| [First native command](native-command.md) | A literal function/test/target, reviewed publication, canonical re-entry and detached execution. |
| [Native text composition](native-text.md) | Reusable text joining, exact separators and caller-owned escaping. |
| [Owned byte buffers](native-byte-buffer.md) | Concrete affine storage, synchronous reads, generic package composition and frozen binary output. |
| [Owned generics and explicit witnesses](native-owned-generics.md) | A symbolic library, buffer and scalar implementations, exact static selection and detached execution. |
| [Structural owned products](native-owned-products.md) | Fixed named affine fields, ordinary metadata, generic Owned payloads and complete consuming decomposition. |
| [Recoverable owned outcomes](native-owned-choices.md) | Explicit success/rejection cases, owner-returning refusal and exhaustive consuming analysis. |
| [Scoped reads of owned children](native-owned-borrows.md) | Generic product/choice inspection through exact witnesses while retaining the original owner. |
| [Dynamic owned sequences](native-owned-sequences.md) | Runtime-sized owned collections, scoped indexed reads, exact element witnesses and consuming drain. |
| [Parameterized owned worklists](native-owned-worklists.md) | One element contract across flat and chunked storage, explicit transfer and complete provisional graph validation. |
| [Source-tied borrowed results](native-owned-read-results.md) | Return generic read-only views across packages, observe stable selection and regain consuming rights after scope exit. |
| [Joined parallel computation](native-parallel.md) | Empty-effect child tasks, owned inputs, generic reductions, fresh child identities and shared quotas. |
| [Reusable generic parallel groups](native-transferable-parallel.md) | Explicit transferable bounds, generic builders, mixed results and exact witnesses. |
| [Immutable byte ranges](native-byte-ranges.md) | Strict binary ranges, explicit backing detachment and source-free package composition. |
| [HTML over HTTP](native-html-http.md) | Separate typed HTML and HTTP libraries composed into a detached service. |
| [Resident execution policy](resident-policy.md) | Optional cumulative quotas and independent deadline/grant controls. |
| [Typed HTML composition](native-html.md) | Recursive inline/block types, exact library transport and an independently authored consumer. |
| [HTTP service and response library](native-http.md) | Typed routes, query input, bounded byte-stream echo, detached serving and reviewed route edits. |
| [Native library](native-library.md) | Generic library creation, exact imports, application-owned types and standalone execution. |
| [Native summary](native-summary.md) | Ordinary counting and complete bounded command results. |
| [Native pagination](native-pagination.md) | Reusable native range selection over a larger result. |
| [Native ranking](native-ranking.md) | Native sorting and bounded selection with measured tradeoffs. |
