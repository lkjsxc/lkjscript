# Native authoring guides

These guides use public product operations and literal native declarations.
Read each guide's tested runtime and boundary; examples are not new compiler
intrinsics or automatically maintained application packages.

| Guide | What it demonstrates |
| --- | --- |
| [Resident execution policy](resident-policy.md) | Development-only nullable cumulative quotas, preserved legacy limits and independent deadline/grant controls. |
| [Typed HTML composition](native-html.md) | Ordinary recursive inline/block types, exact library transport and a separately authored article consumer on public v0.1.44. |
| [HTTP service and response library](native-http.md) | Public v0.1.44 library transport, typed routes, query input, bounded byte-stream echo, detached serving and reviewed route edits. |
| [Native library](native-library.md) | Generic library creation, exact imports, application-owned types and standalone command execution. |
| [Native summary](native-summary.md) | Ordinary counting and complete bounded command results. |
| [Native pagination](native-pagination.md) | Page a larger result with reusable native range selection. |
| [Native ranking](native-ranking.md) | Native sorting and bounded selection with measured tradeoffs. |

[Current status](../status.md) separates development source from immutable releases.
[Generated operations](../generated/operations.md) own public command discovery.
