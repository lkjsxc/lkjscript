## Native-Reference Boundary

**Current through host-independent source lowering.** Native code uses bounded
registered frames with verified typed homes. Strings, paths, products, enums,
options, results, and errors use structural services. Selected lists and
products use exact category/layout-checked invocation-region keys; zero denotes
only an empty list. Bytes and byte vectors use the checked unique runtime.
Returned outcomes retain key-free structural/list snapshots or explicit unique
bytes. Host capabilities, complete lexical ownership adapters, broader
native/VM transitions, and OSR are not smuggled into this slice.
