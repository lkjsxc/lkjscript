# Construction-controlled execution values

Status: accepted for campaign 202609081540; acceptance evidence has its own owner.

The graph-owned standard fold forwards an immutable list through ordinary calls. In the retained
release baseline, forwarding 4,096 items through 1,024 direct countdown calls returns 4,096 in
both tiers while visiting 8,400,896 production and 12,595,200 reference descendants in affine
guards. Removing tail activations did not remove this repeated payload work.

Keep raw values at runtime boundaries. Each evaluator owns a private checked value representation,
its own bounded admission walker and its own constructors. Production prepares nominal affinity
from strictly loaded layouts; reference affinity comes from canonical owners and its independently
reconstructed schema. Neither tier uses the other's classification decisions.

Containment makes a compact proof sufficient: every descendant of an admitted affine-free
aggregate is affine-free. An affine nominal variant may contain only a direct resource in the
selected case. Therefore projections can inherit the appropriate proof without a metadata tree,
subtree scan or cache. Checked ordinary duplication validates the root class; affine owners move.
Raw dense nominal/callable indexes carry a neutral process-local program origin, separate from
classification, so a same-number index from another preparation cannot acquire a valid proof.
This origin is not serialized and confers no admission authority.

Core intrinsics preserve admitted arguments and selected children. Decoded and arbitrary host
results still enter through independent admission. The forwarding matrix measures all admission,
constructor-child and guard-descendant visits, while fault injection must distinguish a restored
rescan even when arithmetic remains correct.

The cutover preserves maintained meaning and every stored encoding. Reversal requires a
disconfirming public-boundary, ownership, resource or independent-proof observation; it must not
restore unchecked slot insertion or weaken the fixed acceptance obligations. Collection copying,
allocation redesign and further language abstractions remain separate work.
