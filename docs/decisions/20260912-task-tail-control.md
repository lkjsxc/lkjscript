# Task tail control

Ordinary graph task functions receive the existing graph tail-call space guarantee.
Canonical function kind and exact signatures admit the disposable normalized dispatch;
terminal analysis follows unconditional edges in linear work. Externals and entry wrappers
keep their existing paths. A transaction body retains its lexical commit continuation.

Production admits the complete callee application, checked arguments, resource provenance,
and task row against the outgoing activation before replacing it. The callee installs its
own row; an empty task row remains a task, and a pure callee removes task permission.
Canonical grants, counters, resources and ancestor transactions belong to the invocation.
Unused affine locals may disappear without completing or releasing the underlying resource.

The independent canonical evaluator resolves and admits a graph target while the outgoing
scope is live. A construction-controlled internal handoff owns its exact canonical function,
substitutions, allowance and checked arguments for one transition. The trampoline consumes
that object after the previous activation and lexical maps have unwound. Ordinary calls
perform ordinary admission; raw entry cannot supply a handoff. This avoids authorizing a
narrow helper's wider target against a surviving broad ancestor.

Negative proof includes outgoing-row widening (also with shared canonical grants), pure to
empty-row task, foreign prepared origins, wrong ordered substitutions, residual operands,
discarded transaction commits, stale/duplicate resource rights and non-tail depth exhaustion.
Failures stop subsequent callbacks. Cancellation is checked before activation installation;
work and allocations remain cumulative. Resource cleanup stays at invocation termination.

The public standard library adds an ordinary `iteration-step<State,Output>` variant and
effect-parametric `task-iterate`; no State/Output capture-safe constraint is needed. Its
callback runs once before deciding continue/done. Fold preserves its public identity and
signature through a sequential private index/state loop over the same persistent list.
Map remains fold plus append. Constant control space does not bound payload retention,
cumulative allocations, runtime, effects or scheduler behavior.

Graph, type, typed-data and canonical bytecode encodings do not change for derived dispatch.
Runtime and verifier identities change only at their interpretation/evidence owners.
The separately frozen effect milestone remains at source `67baaf0b`; this increment is
selected for engineering/integration with publication deferred by its campaign contract.

The reverse-edge algorithm uses dense predecessor links and one bounded queue. This preserves
linear work while making all temporary storage chargeable before allocation; a vector per
destination would otherwise reserve hidden minimum capacities for one-edge lists. Derivation
runs after effect specialization, so the actual closed clone supplies target eligibility.

The rehashed-control probe exposed a strict-loader gap: nominal/callable occurrence inventories
did not compare the complete compiled control flow. This campaign adds exact canonical code
reconstruction under the existing aggregate validation work bound, using point reads from the
already admitted transported closure. It compares evaluation order, locals, operands, jumps and
transaction continuations before normalized tail derivation. The existing lowering owner supplies
this comparison; the reference evaluator remains algorithmically independent. No serialized
contract or supported valid predecessor bytes change. A conditional terminal cycle and a deleted
transaction commit now reject with `artifact_compiled_control_meaning` after every affected object,
map, manifest and envelope hash is recomputed and obsolete map pages are removed.
