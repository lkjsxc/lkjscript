# Release manifest classifier

This retained example constructs a pure classifier for an exact 32-byte binary release manifest through the public JSON CLI. It saves a reachable typed hole, rejects a byte-for-boolean repair without publication or identity consumption, validates and commits an identity-preserving repair, checks all decisions and a bounds trap, renames presentation metadata, restarts the daemon, and executes historical revisions.

Run it with:

```sh
./examples/release-manifest/run.sh
```

The script uses only production release binaries and deletes only its private temporary state directory.
