# Associated Owned BlockRead

The literal program exports a generic BlockRead contract and consumer before two
independent suppliers exist. Flat binds Block to an owned sequence. Chunked binds
Block to real nominal descendants with module-private fields. The consumer
forwards an exact lexical implementation witness and reads source-tied blocks;
it has no caller-selected Block type argument.

Files 01–04 author the consumer, flat supplier, chunked supplier and application.
The application exposes combined, flat and chunked targets. Four handwritten
argument/expected pairs cover empty, one, three and 33 elements, including the
second chunk's 330 value. The three negative requests attempt protected ancestor
consumption, borrowed-owner escape and private foreign-field access.

The maintained public test is:

`native_declarations::native_associated_blockread::native_associated_blockread_consumer_first_four_literals_three_targets_and_detached_bytes`

It uses actual exported package/revision bindings, draft/replan and two complete
artifact builds. Four cases by three targets run attached and detached, giving 24
exact result comparisons. Detached runs remove only their owned source projects
and transports and require joined cleanup with no live handles or capability
calls. Expected results are literal files.

from real public responses. The executable matrix is
