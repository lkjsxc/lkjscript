## Mandatory design gates

Pass each gate with code and executable evidence, not rhetoric.

### Gate 1: authority
There remains one mutable semantic program authority. The new public type value is an API
value and projection of authority, not a second mutable type database.

### Gate 2: identity

ownership, bound, and witness validation mechanism.

previous snapshot.

behavior, and old snapshots remain coherent.

### Gate 8: stack safety

introduced operations.

### Gate 9: simplicity

without a present measured or structural need.

### Gate 10: singular cutover

## One shared exact instantiation mechanism

Factor one exact generic call mechanism that both source-inferred and workspace-explicit calls
use.
Do not copy the current source resolver's instantiation and trait-solver logic into the

Do not make the workspace render a synthetic source call and reparse it.

The mechanism should accept:

- the callee's semantic function identity or validated internal binding;
- its exact function or universal function type;
- canonical exact substitutions supplied in declaration order;
- resolved value argument types;
- the callee's trait bounds;
- the program's trait, product, enum, and implementation facts needed for solving; and
- the current ownership and reference restrictions.
The mechanism should return:

- the exact instantiated parameter types;
- the exact result type;
- canonical substitutions;
- derived trait witnesses;
- any exact metadata required by HIR `GenericInstantiation`; and
- a deterministic semantic error on failure.
The exact sequence is expected to be:

1. Validate the callee is callable.
2. Distinguish non-generic and universal function types.
3. Validate substitution coverage and uniqueness.
4. Canonicalize substitutions in binder declaration order.
5. Substitute the function signature.
6. Validate value arity.
7. Validate exact assignability of every value argument to its instantiated parameter.
8. Apply the same ownership and lexical-reference generic restrictions used by source

9. Resolve each trait bound against the substituted type.
10. Derive auto-trait or explicit implementation witnesses.
11. Validate that every witness refers to current semantic facts.
12. Reject prohibited lexical reference results.
13. Return the exact result and instantiation metadata.

Source analysis may run its current inference first, but then it must canonicalize the result
and call the exact mechanism.
Workspace explicit calls convert stable public type arguments into canonical substitutions and

Do not allow the source path and workspace path to use different assignability, ownership, or
witness rules.
Use the current production generic route. Do not add monomorphization as a requirement for
correctness.
