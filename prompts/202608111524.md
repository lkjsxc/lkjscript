## Primary product problem

not express the more precise semantic fact that the author intends to read a value by a
particular name but has not selected a stable binding identity. Encoding that fact only in a
goal string forces an agent to reconstruct structured intent from prose and prevents
deterministic candidate discovery and resolution.

- The workspace needs a first-class unresolved semantic value reference.
- The unresolved state must preserve known type and lexical context.
- The unresolved state must preserve a deterministic requested-name hint.
- The unresolved state must not point to a guessed binding.
- The unresolved state must not create a reference or dependency edge to a non-selected
  candidate.
- The unresolved state must not contain a hidden executable load.
- The unresolved state must block compilation before complete HIR derivation.
- The unresolved state must expose deterministic legal resolution candidates.
- The unresolved state must be resolvable through a typed atomic edit.
- Resolution must reuse canonical load, visibility, type, and ownership validation.

## Closing instruction

Inspect, decide, implement, delete displaced paths, test, measure only where justified,
update authority documents, verify, commit, and stop. A smaller complete
unresolved-reference lifecycle is better than a broad partially implemented recovery
architecture.

weak coding agent consuming the public semantic API. Correct every item that cannot be
answered from structured state, canonical validation, or focused tests.
